# 7️⃣ Crescimento de Bactérias

## 📌 Objetivo

Analisar o crescimento percentual diário de bactérias em uma colônia.

## 🧠 O que o programa faz

* percorre uma lista com a quantidade de bactérias;
* compara o valor atual com o dia anterior;
* calcula o percentual de crescimento diário.

## 📚 Conceitos praticados

* listas;
* laços `for`;
* índices;
* operações matemáticas;
* porcentagem;
* análise de dados.

## 💡 Fórmula utilizada

```python
100 * (atual - anterior) / anterior
```
